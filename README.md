## 2. Разработка модулей

### Startup Module
- Создана функция `nexus_startup()`.
- Реализована заставка NEXUS AI.
- Добавлен цикл отображения прогресса запуска.
- Изучены заголовочные файлы и защита от повторного подключения.

### Menu Module
- Создана функция `nexus_menu()`.
- Реализовано главное меню.
- Добавлен цикл работы меню.
- Реализована обработка команд через `switch`.
- Подключены остальные модули.

### Commands Module
- Создана функция `get_command()`.
- Реализовано получение команд пользователя.
- Начато использование `enum` для обозначения команд.

### System Module
- Создана функция `nexus_system_info()`.
- Подключён вывод системной информации к главному меню.

### Shutdown Module
- Создана функция `nexus_shutdown()`.
- Реализовано завершение работы через меню.

### AI Module
- Создана функция `nexus_check_ai()`.
- Реализована проверка наличия Ollama через `system()` и `where.exe ollama`.

  - `AI_SUCCESS = 1`
- Подключена проверка Ollama к главному меню.

```c
void nexus_info(int version, int status, int year)
{
    printf("========================\n");
    printf("        NEXUS AI        \n");
    printf("========================\n");
    printf("Version: %d\n", version);
    printf("Status: %d\n", status);
    printf("Year: %d\n", year);
}

void nexus_print_info(void)
{
    nexus_info(1, 1, 2026);
}
```
